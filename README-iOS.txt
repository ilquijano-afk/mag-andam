Unity project source is at the repository root. Main scene: Assets/Scenes/MainGame.unity. Use Unity 6000.6.5f1, iOS Development, IL2CPP and Metal. The prepared cloud draft selects macOS Tahoe, Apple Silicon, Mac Standard and Xcode 26.5.0. Pre-export method: AndamRunnerEditor.IOSBuildTools.Configure. See Docs/iOS-Cloud-Build.md. Apple signing files must be supplied separately before an iOS target can be saved or built. This repository contains source, not a signed IPA.
